Changing the zone number of a tune_zone setting in the editor deleted another setting of that zone. With `tune_zone 1 gravity 0` and `tune_zone 2 player_collision 0`, updating the second one to `tune_zone 1 player_collision 0` removed the gravity line.

`CheckCollision` returned the index of the last line with the same zone number even when there was no collision, and Update deleted that line. It now returns -1 in that case, as its comment says.

Closes #10852
